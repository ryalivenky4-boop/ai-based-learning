# SAMARTH-STAT (समर्थ-सांख्यिकी)
### AI-Enabled Skill Intelligence & Capacity Building Platform for India's Official Statistical System
**Problem Statement ID:** 26101  
**Organization:** Ministry of Statistics and Programme Implementation (MoSPI)  
**Department:** Data Informatics & Innovation Division (DIID) & National Statistical Systems Training Academy (NSSTA)  
**Category:** Software | **Theme:** Smart Education  
**Ecosystem Integration:** iGOT Karmayogi (Mission Karmayogi - NPCSCB) & NSSTA TPAC Training Calendar  

---

## 🏛️ Background & Overview
India's statistical system is undergoing rapid modernization with increasing adoption of Artificial Intelligence (AI), Machine Learning (ML), Big Data Analytics, GIS, cloud computing, and advanced statistical methodologies (PLFS, National Accounts SNA 2008/2025, ASI, CPI, SDG tracking).

Statistical personnel across cadres—including the **Indian Statistical Service (ISS)**, **Subordinate Statistical Service (SSS)**, Field Investigators, and Data Informatics Officers—require continuous, targeted upskilling. While **iGOT Karmayogi** hosts a rich repository of learning resources, statistical personnel face challenges in identifying the most relevant courses aligned with their job roles, current competencies, and promotional pathways.

**SAMARTH-STAT** is an intelligent, AI-enabled competency intelligence and personalized capacity building platform tailored specifically for India's Official Statistical System.

---

## 🚀 Key Modules & Capabilities

### 1. 🎯 Multi-Domain Competency Profiling & Personas
- Standardized mapping across **4 Core Domains & 24 Sub-Competencies**:
  - **Statistical Competencies:** Survey Sampling, National Accounts (SNA), Price Statistics (CPI/IIP), Labour Statistics (PLFS), Industrial Statistics (ASI), SDG Indicators (NIF), Data Quality Framework (DQAF) & SDMX.
  - **Technical Competencies:** Python for Official Microdata, R for Econometrics, SQL Data Warehouses, QGIS Spatial Analytics, AI/ML in Surveys, Cloud & Open Data APIs.
  - **Digital Governance:** Government Cybersecurity (CERT-In), Data Privacy & DPDP Act 2023, DPI & MeghRaj Cloud, e-Office 7.0 & DSC.
  - **Behavioural & Managerial:** Civil Services Conduct Rules 1964, Survey Project Management, Policy Briefing, Strategic Leadership.
- Preloaded authentic MoSPI personas across divisions (FOD Jaipur, NAD New Delhi, DIID Headquarters).

### 2. 📡 Automated Skill-Gap Analysis & HTML5 Radar Visualization
- Dynamic comparison of an officer's current assessed proficiency against target role benchmarks (JSO, SSO, Assistant Director, Deputy Director, Data Informatics Officer).
- Interactive **HTML5 Canvas Radar Chart** with dual-polygon overlay (Current Profile vs Role Target).
- Severity classification: **Critical Gaps** ($\text{Gap} \ge 2$), **Moderate Gaps** ($\text{Gap} = 1$), and **Proficient**.
- Real-time interactive skill simulator sliders.

### 3. 🎓 Dual-Track Personalized Pathway (iGOT Karmayogi + NSSTA TPAC)
- Structured 3-Phase Milestone roadmap:
  - **Phase 1:** Urgent Foundation & Critical Gap Remediation (Weeks 1–4)
  - **Phase 2:** Advanced Core Competency & Field Analytics (Weeks 5–10)
  - **Phase 3:** Strategic Leadership & Emerging AI Technologies (Weeks 11–16)
- Bridges online asynchronous micro-credentials from **iGOT Karmayogi** with residential/hybrid in-service workshops from the **NSSTA TPAC 2025-26 Training Calendar** (Greater Noida campus).
- **Two-Way iGOT Telemetry Simulation:** Synchronizes course progress, verifies badges, awards Karma Credits, and dynamically updates competency scores.

### 4. 🧠 AI Assessment Studio: Document-to-MCQ & Quiz Engine
- Ingests official MoSPI publications (or uploaded PDFs/DOCX/text manuals):
  - *PLFS Methodology & Sampling Design*
  - *Handbook of National Accounts Statistics (GVA/GDP)*
  - *Annual Survey of Industries (ASI) Scrutiny Manual*
  - *MoSPI Data Quality Assurance Framework (DQAF) & SDMX*
  - *Consumer Price Index (CPI) Technical Manual*
- Dynamic AI generation of 4-option objective MCQs with:
  - Bloom's Cognitive Taxonomy tags (*Remembering, Understanding, Applying, Analyzing*).
  - Variable difficulty levels (Easy, Medium, Hard).
  - Authoritative conceptual explanations and exact source citations.
- **Interactive Timed Quiz Player:** Live timer, question palette, flag-for-review, and instant scorecards with confetti celebrations.
- **Automated Remedial Prescription:** Immediately maps failed quiz questions to the exact iGOT course needed to close the knowledge gap.
- **Trainer Studio:** Review, edit, add questions, and export assessments in QTI/JSON.

### 5. 📊 Ministry-Wide DIID & Leadership Analytics Dashboard
- Workforce competency heatmaps across all MoSPI Divisions (**FOD, NAD, ESD, SDRD, DIID, SSD**).
- Cadre comparison (**ISS vs SSS**).
- **Predictive Capacity Building Analytics (2025-2027):** Forecasts skill deficits for upcoming national statistical milestones (7th Economic Census, SNA 2025 transition, DPDP Act compliance, and AI auto-coding).
- One-click export of workforce competency audit reports (JSON/CSV).

### 6. 🤖 Karmayogi StatSahayak (AI Statistical Tutor)
- Specialized conversational AI copilot for official statistics.
- Preconfigured prompts for GVA vs GDP, rotational panel designs, ASI balance checks, Python microdata scripts, and SDMX standards.
- Deep-links directly into relevant iGOT courses and diagnostic assessments.

## 💻 Local Development Setup

### Prerequisites
- Node.js (v18 or higher)
- npm (v9 or higher)

### Installation & Execution
```bash
# 1. Clone repository
git clone https://github.com/ryalivenky4-boop/ai-based-learning.git
cd ai-based-learning

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build production bundle
npm run build
```

The application will be available at `http://localhost:5173/`.
